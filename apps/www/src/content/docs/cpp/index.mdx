## Perché imparare il C++

Videogiochi, browser e servizi di streaming usano spesso software scritto, almeno in parte, in C++.

Il C++ è adatto ai programmi che devono essere veloci, usare poca memoria o controllare direttamente l'hardware del computer.

Imparare il C++ ti mette a contatto con concetti come tipi, memoria e compilazione. Richiede più attenzione rispetto ad altri linguaggi, ma ti aiuta a capire che cosa succede tra il codice che scrivi e il programma che esegui.

## Cos'è il C++

Il **C++** è un linguaggio di programmazione nato come evoluzione del C. Il suo nome si legge “C più più”. In programmazione, `++` indica spesso un incremento: il nome suggeriva quindi un C arricchito con nuove possibilità.

Lo trovi ovunque:

- **Sistemi operativi** — parti di Windows e Linux sono scritte in C++
- **Videogiochi** — motori grafici come Unreal Engine usano C++
- **Browser** — Chrome e Firefox hanno il motore di rendering scritto in C++
- **Software scientifico e finanziario** — per elaborazioni che richiedono prestazioni elevate
- **Dispositivi embedded** — microcontrollori, robot, sistemi industriali

## C++ e Python: compiti e differenze

Se hai già studiato Python, ecco le differenze più importanti:

| Caratteristica         | C++                                        | Python                                      |
| ---------------------- | ------------------------------------------ | ------------------------------------------- |
| Come si esegue         | Di solito compilato prima dell'avvio       | Di solito eseguito da un interprete         |
| Prestazioni            | Offre molto controllo e può essere rapido  | Privilegia spesso semplicità e produttività |
| Sintassi               | Più precisa e rigida                       | Più semplice e flessibile                   |
| Tipi delle variabili   | Obbligatori da dichiarare                  | Non obbligatori                             |
| Gestione della memoria | Esplicita, ma aiutata da strumenti moderni | Gestita automaticamente                     |

In C++ devi dichiarare il tipo delle variabili e terminare molte istruzioni con `;`. Hai anche più controllo sulle risorse del programma. Questo controllo può portare a ottime prestazioni, ma non rende automaticamente veloce ogni programma: contano anche gli algoritmi e il modo in cui scrivi il codice.

## Come funziona il C++?

Il C++ è un linguaggio **compilato**. Significa che, prima di eseguire il programma, il codice che scrivi viene trasformato in istruzioni dirette per il processore da un programma chiamato **compilatore**.

Il flusso di lavoro è:

1. Scrivi il codice in un file con estensione `.cpp`
2. Il compilatore legge il file e lo trasforma in un programma eseguibile (`.exe` su Windows, senza estensione su Linux e macOS)
3. Esegui il programma

Se il compilatore trova un errore, non crea l'eseguibile e mostra un messaggio. All'inizio è normale: leggeremo questi messaggi per capire quale riga correggere.

## Il primo programma

Per vedere il percorso completo, ecco un programma che stampa un saluto:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!\n";
    return 0;
}
```

Output:

```
Hello, World!
```

`main` è il punto da cui parte il programma. La riga con `cout` mostra il testo. Non devi ancora ricordare `#include`, `using namespace std` o `return`: li vedremo nelle pagine successive.

## Le versioni del C++

Il C++ viene aggiornato periodicamente con nuove funzionalità. Le versioni principali sono:

- **C++98** — la prima versione standardizzata
- **C++11** — un grande aggiornamento con molte funzionalità moderne
- **C++14, C++17, C++20 e versioni successive** — miglioramenti progressivi

In questa guida useremo C++ moderno ed eviteremo tecniche superate quando esiste un'alternativa più sicura e leggibile.
