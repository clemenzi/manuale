## Scegliere il tipo di una colonna

**Quando crei una colonna, devi decidere che cosa può contenere.** Il tipo stabilisce la forma dei valori ammessi.

Una colonna destinata a una data non dovrebbe contenere una frase lunga.

## Alcuni tipi che userai spesso

| Tipo            | Significato semplice    | Esempio         |
| --------------- | ----------------------- | --------------- |
| `INT`           | numero intero           | `42`            |
| `VARCHAR(100)`  | testo corto             | `'Luca'`        |
| `TEXT`          | testo lungo             | una descrizione |
| `DATE`          | data                    | `2026-04-24`    |
| `BOOLEAN`       | vero o falso            | `TRUE`          |
| `DECIMAL(10,2)` | numero decimale preciso | `19.99`         |

## Perché la scelta conta davvero

**Il tipo di dato determina come il database salva e confronta l'informazione e quali errori può impedire.**

Per esempio, una colonna prezzo va trattata in modo diverso da una colonna nome. Una colonna data si comporta in modo diverso da un testo normale.

## `VARCHAR` e `TEXT`: sembrano simili, ma non sono uguali

All'inizio può sorgere una domanda: "se entrambi contengono testo, perché esistono due tipi?"

- `VARCHAR(100)` dice: **qui entra testo, ma con un limite di lunghezza**
- `TEXT` dice: **qui può entrare anche testo molto lungo**

Per un nome o un'email, spesso `VARCHAR` è una scelta naturale. Per una recensione o una descrizione dettagliata, `TEXT` può avere più senso.

## Numeri interi o numeri con virgola

**`INT` è adatto a quantità, contatori e identificatori.** Per esempio, puoi usarlo per le unità in magazzino.

**`DECIMAL` è più adatto a prezzi, importi e altri valori per cui la precisione è importante.** È il tipo da preferire per le somme di denaro.

## Un esempio dentro una tabella

In questa tabella i tipi descrivono già lo scopo delle colonne:

```sql
CREATE TABLE prodotti (
    id INT,
    nome VARCHAR(100),
    prezzo DECIMAL(10,2),
    disponibile BOOLEAN,
    data_creazione DATE
);
```

Da questa struttura si vede che `prezzo` è un numero preciso, `disponibile` è un valore vero/falso e `data_creazione` è una data.

:::tip
Se sei indeciso, chiediti: "che tipo di dato rappresenta nel mondo reale?" La risposta restringe la scelta.
:::
