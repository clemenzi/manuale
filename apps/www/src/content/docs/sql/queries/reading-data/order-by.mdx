## Ordinare i risultati

**`ORDER BY` stabilisce l'ordine dei risultati.** Senza questa clausola non devi fare affidamento sull'ordine delle righe.

Lo stesso elenco può essere più utile se ordinato per nome, prezzo o data.

```sql
SELECT nome
FROM clienti
ORDER BY nome ASC;
```

`ASC` vuol dire crescente. `DESC` vuol dire decrescente.

## Quando lo usi davvero

Usa `ORDER BY` quando vuoi:

- nomi in ordine alfabetico
- prezzi dal più alto al più basso
- date dalla più recente alla più vecchia
- punteggi in classifica

## Un altro esempio chiaro

```sql
SELECT nome, totale
FROM ordini
ORDER BY totale DESC;
```

Qui gli ordini con il totale più alto compariranno per primi.

## Un dettaglio importante

**L'ordinamento avviene sul risultato della query.** Prima selezioni le righe, poi ne stabilisci l'ordine.

Per questo `ORDER BY` si usa spesso dopo `WHERE`, quando hai già filtrato ciò che ti interessa.
