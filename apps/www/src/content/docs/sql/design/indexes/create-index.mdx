title: CREATE INDEX
description: Come creare un indice per velocizzare certe ricerche nel database.
---

## Un indice aiuta a trovare le righe

**Un indice aiuta il database a trovare più rapidamente certe righe.** Senza indice, il database può dover leggere molti dati. Con un indice adatto, può restringere la ricerca.

Immagina un libro di 800 pagine. Se cerchi la parola "spedizione" senza indice, devi sfogliarlo tutto; con l'indice vai alle pagine pertinenti.

Nel database succede qualcosa di simile.

## Un esempio piccolo

Questa istruzione crea un indice sulla colonna `email` della tabella `clienti`:

```sql
CREATE INDEX idx_clienti_email
ON clienti(email);
```

Da quel momento, una ricerca per email può leggere l'indice invece di controllare tutte le righe.

```sql
SELECT nome
FROM clienti
WHERE email = 'luca@email.it';
```

## Quando ha senso aggiungerlo

Gli indici sono utili soprattutto su colonne che usi spesso per:

- filtrare con `WHERE`
- ordinare con `ORDER BY`
- collegare tabelle nelle join

## Il compromesso da ricordare

**Gli indici accelerano alcune letture, ma hanno un costo.** Occupano spazio e possono rallentare inserimenti, aggiornamenti ed eliminazioni.

Per questo non conviene indicizzare ogni colonna: vanno scelti gli indici utili alle query reali.

:::tip
Prima di aggiungere indici, osserva quali query sono lente. Un indice scelto bene aiuta; molti indici inutili aumentano solo spazio e lavoro di manutenzione.
:::
