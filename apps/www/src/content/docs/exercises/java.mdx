import java.util.Scanner;

import java.util.Scanner;

### Esercizio 50

Creare un piccolo menu ripetuto con `while` e `switch` che termini quando l'utente sceglie `0`.

<details>
<summary>Soluzione spiegata</summary>

Uniamo un ciclo ripetuto e uno `switch` per gestire più scelte finché non arriva il comando di uscita.

```java
import java.util.Scanner;

public class MenuRipetuto {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int scelta = -1;

        while (scelta != 0) {
            System.out.println("1. Saluta");
            System.out.println("2. Mostra numero fisso");
            System.out.println("0. Esci");
            System.out.print("Scelta: ");
            scelta = scanner.nextInt();

            switch (scelta) {
                case 1:
                    System.out.println("Ciao!");
                    break;
                case 2:
                    System.out.println(42);
                    break;
                case 0:
                    System.out.println("Uscita");
                    break;
                default:
                    System.out.println("Scelta non valida");
            }
        }

        scanner.close();
    }
}
```

Il programma continua a mostrare il menu finché l'utente non inserisce `0`.

</details>
