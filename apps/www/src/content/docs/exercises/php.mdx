### Esercizio 1

Inviare in output il testo `Ciao, PHP!`.

<details>
<summary>Soluzione spiegata</summary>

Una sola istruzione `echo` stampa il testo richiesto.

```php
<?php
echo "Ciao, PHP!";
```

L'output coincide con la frase richiesta.

</details>

### Esercizio 2

Conservare un nome e un'età in due variabili e inviarli in output.

<details>
<summary>Soluzione spiegata</summary>

Salviamo i due valori e poi li stampiamo con `echo`.

```php
<?php
$nome = "Luca";
$eta = 17;

echo $nome . "\n";
echo $eta;
```

Così puoi riutilizzare i dati senza riscriverli.

</details>

<details>
<summary>Soluzione spiegata</summary>

```php
<?php
$a = 12;
$b = 8;
$somma = $a + $b;

echo $somma;
```

`$somma` contiene il totale che stampiamo alla fine.

```php
$base = 5;
```

L'output contiene il valore calcolato.

### Esercizio 5

<details>
<summary>Soluzione spiegata</summary>

```php
<?php
const IVA = 0.22;
```

```php
$a = (int) readline("Primo numero: ");
```

### Esercizio 11

Verificare se un numero intero è pari o dispari.

<details>
<summary>Soluzione spiegata</summary>

Usiamo l'operatore `%` per controllare il resto della divisione per `2`.

```php
<?php
$numero = (int) readline("Numero: ");

if ($numero % 2 === 0) {
    echo "Pari";
} else {
    echo "Dispari";
}
```

Se il resto è zero, il numero è pari; negli altri casi è dispari.

</details>

### Esercizio 12

Determinare se un numero è positivo, negativo oppure zero.

<details>
<summary>Soluzione spiegata</summary>

Con `if`, `elseif` ed `else` gestiamo i tre casi possibili.

```php
<?php
$numero = (int) readline("Numero: ");

if ($numero > 0) {
    echo "Positivo";
} elseif ($numero < 0) {
    echo "Negativo";
} else {
    echo "Zero";
}
```

PHP valuta le condizioni dall'alto verso il basso, fino al primo caso valido.

</details>

### Esercizio 16

Verificare se un anno è bisestile.

<details>
<summary>Soluzione spiegata</summary>

Un anno è bisestile se è divisibile per `400`, oppure se è divisibile per `4` ma non per `100`.

```php
<?php
$anno = (int) readline("Anno: ");

if ($anno % 400 === 0 || ($anno % 4 === 0 && $anno % 100 !== 0)) {
    echo "Bisestile";
} else {
    echo "Non bisestile";
}
```

La condizione combina `&&` e `||` per rappresentare la regola completa.

</details>

### Esercizio 18

```php
$a = (int) readline("Primo numero: ");

if (($a >= 0 && $b >= 0) || ($a < 0 && $b < 0)) {
```

La condizione verifica entrambe le combinazioni possibili.

</details>

### Esercizio 19

```php
$totale = (float) readline("Totale: ");
```

Il programma conferma l'ordine solo quando entrambe le condizioni sono vere.

```php
$giorno = readline("Giorno: ");

switch ($giorno) {

    case "domenica":
```

```php
$numero = 1;
```

```php
$n = (int) readline("n: ");
```

### Esercizio 30

Cercare un valore in un array e stampare la sua posizione oppure `-1`.

<summary>Soluzione spiegata</summary>

La ricerca lineare controlla gli elementi uno alla volta, fermandosi quando trova quello richiesto.

```php
<?php
$numeri = [15, 3, 8, 42, 7];
```

### Esercizio 33

```php
$testo = readline("Testo: ");

```

Il ciclo visita un carattere alla volta e aggiorna il conteggio solo quando trova una vocale.

Creare un form con POST che richiede il nome, controlla che non sia vuoto e rimostra il valore inserito.

Controlliamo il metodo della richiesta, validiamo il dato e usiamo `htmlspecialchars()` per rimetterlo in pagina in modo sicuro.

```php
<?php
$nome = $_POST["nome"] ?? "";

        type="text"
        name="nome"

```

Anche dopo un errore, il valore già inserito resta nel campo.

### Esercizio 49

Eseguire una query preparata con PDO per cercare un utente tramite email.

<details>
<summary>Soluzione spiegata</summary>

Prepariamo la query con un placeholder e passiamo il valore a `execute()` invece di incollarlo nella stringa SQL.

```php
<?php
$dsn = "mysql:host=localhost;dbname=negozio;charset=utf8mb4";
$utente = "root";
$password = "";
$email = "luca@example.com";

try {
    $pdo = new PDO($dsn, $utente, $password, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]);

    $stmt = $pdo->prepare("SELECT * FROM utenti WHERE email = :email");
    $stmt->execute(["email" => $email]);

    $utenteTrovato = $stmt->fetch();

    if ($utenteTrovato) {
        echo "Utente trovato";
    } else {
        echo "Nessun utente trovato";
    }
} catch (PDOException $errore) {
    echo "Impossibile collegarsi al database";
}
```

Le query preparate separano il codice SQL dai dati esterni e riducono il rischio di SQL injection.

</details>

### Esercizio 50

Creare una classe `Conto` con saldo privato, costruttore, metodo per depositare e metodo per leggere il saldo.

<details>
<summary>Soluzione spiegata</summary>

Qui il costruttore inizializza il saldo, mentre `private` e i metodi pubblici ne controllano l'accesso.

```php
<?php
class Conto {
    private float $saldo;

    public function __construct(float $saldoIniziale) {
        $this->saldo = $saldoIniziale;
    }

    public function deposita(float $importo): void {
        if ($importo > 0) {
            $this->saldo += $importo;
        }
    }

    public function leggiSaldo(): float {
        return $this->saldo;
    }
}

$conto = new Conto(100);
$conto->deposita(25);

echo $conto->leggiSaldo();
```

Il saldo non può essere modificato direttamente dall'esterno, ma solo attraverso i metodi scelti dalla classe.

</details>
