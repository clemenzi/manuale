## Cosa e una stringa

Una stringa è testo: un nome, un messaggio, una email o una frase.

```php
<?php
$nome = "Luca";
$saluto = 'Ciao';
```

Puoi usare virgolette doppie o singole, a seconda del risultato che ti serve.

## Virgolette doppie e singole

Con le virgolette doppie PHP interpreta le variabili dentro la stringa.

```php
<?php
$nome = "Luca";
echo "Ciao $nome";
```

Output:

```text
Ciao Luca
```

Con le virgolette singole il testo resta letterale.

```php
<?php
$nome = "Luca";
echo 'Ciao $nome';
```

Output:

```text
Ciao $nome
```

## Concatenazione

Per unire stringhe usa l'operatore punto `.`.

```php
<?php
$nome = "Sara";
$messaggio = "Ciao " . $nome . "!";

echo $messaggio;
```

## Funzioni comuni

PHP offre diverse funzioni per lavorare con il testo.

```php
<?php
$testo = "Manuale PHP";

echo strlen($testo);
```

`strlen` conta i caratteri in byte. Per testi con lettere accentate può servire `mb_strlen`, se l'estensione `mbstring` è disponibile.

Altre funzioni utili:

- `strtolower($testo)` porta in minuscolo
- `strtoupper($testo)` porta in maiuscolo
- `trim($testo)` toglie spazi all'inizio e alla fine
- `str_replace("PHP", "web", $testo)` sostituisce testo

## Testo ricevuto dagli utenti

Quando mostri in una pagina HTML il testo inserito da un utente, usa `htmlspecialchars`.

```php
<?php
echo htmlspecialchars($nome, ENT_QUOTES, 'UTF-8');
```

Così eviti che il testo pericoloso venga interpretato come HTML.

## Leggere una parte di testo

Puoi estrarre una parte di una stringa con `substr`.

```php
<?php
$codice = "ORD-2026-15";
$prefisso = substr($codice, 0, 3);

echo $prefisso;
```

Output:

```text
ORD
```

Il secondo numero indica da dove partire, il terzo quanti caratteri prendere.

## Controllare se un testo contiene una parola

```php
<?php
$email = "luca@example.com";

if (str_contains($email, "@")) {
    echo "Sembra una email";
}
```

Questo non basta per validare una email, ma mostra come controllare se un testo contiene una determinata parte.

## Errore comune: dimenticare gli spazi nella concatenazione

```php
<?php
$nome = "Luca";
echo "Ciao" . $nome;
```

Output:

```text
CiaoLuca
```

Lo spazio va inserito esplicitamente:

```php
<?php
echo "Ciao " . $nome;
```
