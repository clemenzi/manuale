## Cosa e un array

Un array è una variabile che contiene più valori. Puoi immaginarlo come una fila di caselle numerate.

```php
<?php
$frutti = ["mela", "pera", "banana"];
```

Ogni elemento ha una posizione, chiamata **indice**. In PHP il primo indice è `0`.

## Leggere un elemento

```php
<?php
$frutti = ["mela", "pera", "banana"];

echo $frutti[0];
```

Output:

```text
mela
```

`$frutti[1]` contiene `"pera"`.

## Aggiungere elementi

Puoi aggiungere un valore in fondo all'array usando `[]`.

```php
<?php
$frutti = ["mela", "pera"];
$frutti[] = "banana";

print_r($frutti);
```

`print_r` mostra la struttura in un formato leggibile, utile mentre studi.

## Contare elementi

```php
<?php
$frutti = ["mela", "pera", "banana"];

echo count($frutti);
```

Output:

```text
3
```

## Scorrere un array

Con `foreach` puoi lavorare su ciascun elemento.

```php
<?php
$frutti = ["mela", "pera", "banana"];

foreach ($frutti as $frutto) {
    echo $frutto . "\n";
}
```

A ogni giro `$frutto` contiene un valore diverso.

## Modificare un elemento

Puoi cambiare un valore usando il suo indice.

```php
<?php
$frutti = ["mela", "pera", "banana"];
$frutti[1] = "arancia";

print_r($frutti);
```

Ora l'elemento che conteneva `pera` contiene `arancia`.

## Errore comune: dimenticare che si parte da zero

In un array di tre elementi, gli indici sono `0`, `1` e `2`.

```php
<?php
$frutti = ["mela", "pera", "banana"];

echo $frutti[3];
```

`$frutti[3]` non esiste: il terzo elemento è `$frutti[2]`.

## A cosa servono davvero gli array

Gli array sono utili quando hai più valori dello stesso tipo, come nomi, prezzi, voti, messaggi o prodotti.

```php
<?php
$prezzi = [10, 20, 15];
$totale = 0;

foreach ($prezzi as $prezzo) {
    $totale += $prezzo;
}

echo $totale;
```

Qui l'array permette di calcolare il totale senza creare tre variabili separate.

## Prova tu

Crea un array con tre nomi. Poi usa `foreach` per stampare `Ciao` seguito da ogni nome.
