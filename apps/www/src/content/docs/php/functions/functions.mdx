## Cosa e una funzione

Una funzione è un blocco di codice con un nome. La scrivi una volta e puoi usarla più volte.

È come una ricetta: invece di riscrivere tutti i passaggi, la richiami quando serve.

## Dichiarare una funzione

```php
<?php
function saluta() {
    echo "Ciao!";
}
```

Questo codice definisce la funzione, ma non la esegue ancora.

## Chiamare una funzione

Per eseguirla, scrivi il suo nome seguito dalle parentesi.

```php
<?php
function saluta() {
    echo "Ciao!";
}

saluta();
```

Output:

```text
Ciao!
```

## Riutilizzare codice

Una funzione evita di ripetere lo stesso codice.

```php
<?php
function mostraSeparatore() {
    echo "---\n";
}

mostraSeparatore();
echo "Prodotti\n";
mostraSeparatore();
echo "Totale\n";
mostraSeparatore();
```

Se vuoi cambiare il separatore, modifichi una sola funzione.

## Nomi chiari

Il nome dovrebbe indicare che cosa fa la funzione.

```php
<?php
function calcolaTotale() {
    echo 10 + 5;
}
```

`calcolaTotale` descrive meglio lo scopo di `faiCosa`.

> **Suggerimento:** una funzione dovrebbe fare una cosa principale. Se fa troppe cose, diventa difficile da capire e da riusare.

## Una funzione con un compito chiaro

Immagina di dover mostrare più volte il prezzo con la parola `euro`.

```php
<?php
function mostraPrezzo($prezzo) {
    echo $prezzo . " euro";
}

mostraPrezzo(12);
```

La funzione non deve conoscere tutti i prodotti del programma: mostra soltanto un prezzo. Per questo è facile da capire.

## Prima senza funzione, poi con funzione

All'inizio potresti scrivere:

```php
<?php
echo "Ciao Luca\n";
echo "Ciao Sara\n";
```

Con una funzione elimini la ripetizione:

```php
<?php
function saluta($nome) {
    echo "Ciao $nome\n";
}

saluta("Luca");
saluta("Sara");
```

Il vantaggio non è scrivere meno righe a tutti i costi, ma dare un nome a un'azione.

## Errore comune: chiamare la funzione con un nome diverso

```php
<?php
function saluta() {
    echo "Ciao";
}

saluto();
```

`saluta` e `saluto` sono due nomi diversi. PHP cercherà una funzione che non esiste.
