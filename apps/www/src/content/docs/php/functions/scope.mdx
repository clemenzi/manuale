---

## Cosa significa scope

Lo **scope** è la zona in cui una variabile esiste ed è leggibile.

Una variabile creata dentro una funzione non è automaticamente disponibile fuori, e una variabile creata fuori non entra automaticamente nella funzione.

## Variabili locali

```php
<?php
function saluta() {
    $nome = "Luca";
    echo $nome;
}

saluta();
```

`$nome` esiste solo dentro la funzione `saluta`.

Questo codice invece non funziona come potresti aspettarti:

```php
<?php
function preparaNome() {
    $nome = "Luca";
}

preparaNome();
echo $nome;
```

Fuori dalla funzione, `$nome` non esiste.

## Parametri

Il modo più chiaro per portare dati dentro una funzione è usare i parametri.

```php
<?php
function saluta($nome) {
    echo "Ciao $nome";
}

saluta("Sara");
```

## Valori di ritorno

Il modo più chiaro per portare dati fuori da una funzione è usare `return`.

```php
<?php
function creaMessaggio($nome) {
    return "Ciao $nome";
}

$messaggio = creaMessaggio("Marta");
echo $messaggio;
```

## Variabili globali

PHP permette di usare `global`, ma è meglio limitarlo.

```php
<?php
$iva = 22;

function mostraIva() {
    global $iva;
    echo $iva;
}
```

Il codice funziona, ma la funzione dipende da un valore esterno. Con parametri e `return`, il collegamento è più chiaro.

## Perché lo scope aiuta

Lo scope riduce il rischio che una variabile venga modificata per errore da una parte lontana del programma. Una funzione con parametri chiari è più prevedibile.

```php
<?php
function applicaSconto($prezzo, $sconto) {
    return $prezzo - $sconto;
}

$totale = applicaSconto(30, 5);
echo $totale;
```

La funzione lavora solo con i valori che riceve e non deve cercare variabili nascoste nel resto del file.

## Stesso nome, scope diverso

Puoi avere variabili con lo stesso nome in scope diversi.

```php
<?php
$nome = "Luca";

function saluta() {
    $nome = "Sara";
    echo $nome;
}

saluta();
echo $nome;
```

Dentro la funzione `$nome` vale `Sara`. Fuori vale ancora `Luca`.

## Regola pratica

Quando scrivi una funzione, prova a passarle tutto ciò che le serve tramite parametri. Se deve produrre un risultato, usa `return`. Considera `global` l'ultima scelta.
