title: Parametri e valori di ritorno
description: Come passare dati a una funzione e ricevere un risultato.
---

## Parametri e argomenti

Una funzione può ricevere dati dall'esterno. I nomi scritti nella definizione si chiamano **parametri**.

```php
<?php
function saluta($nome) {
    echo "Ciao $nome";
}

saluta("Luca");
```

`$nome` è il parametro. `"Luca"` è l'argomento passato quando chiami la funzione.

## Piu parametri

```php
<?php
function somma($a, $b) {
    echo $a + $b;
}

somma(3, 4);
```

Output:

```text
7
```

## return

`return` restituisce un valore al codice che ha chiamato la funzione.

```php
<?php
function somma($a, $b) {
    return $a + $b;
}

$totale = somma(3, 4);
echo $totale;
```

La funzione non stampa direttamente: calcola e restituisce il risultato.

## Valori predefiniti

Puoi assegnare un valore predefinito a un parametro.

```php
<?php
function saluta($nome = "ospite") {
    return "Ciao $nome";
}

echo saluta();
```

Output:

```text
Ciao ospite
```

## Type declarations di base

Puoi indicare il tipo di dato atteso.

```php
<?php
function calcolaIva(float $prezzo): float {
    return $prezzo * 0.22;
}
```

`float $prezzo` indica che il parametro deve essere un numero decimale. `: float` indica che la funzione restituisce un numero decimale.

Queste indicazioni rendono più facili da trovare gli errori.

## echo o return?

Usa `echo` per mostrare qualcosa subito. Usa `return` per restituire un valore al resto del programma.

```php
<?php
function creaSaluto($nome) {
    return "Ciao $nome";
}

$messaggio = creaSaluto("Luca");
echo $messaggio;
```

Questa funzione è più flessibile: puoi stampare il messaggio, salvarlo, inviarlo in una email o combinarlo con altro testo.

## Parametri con nomi chiari

I parametri sono variabili locali della funzione. Scegli nomi che ne descrivano il ruolo.

```php
<?php
function calcolaTotale($prezzo, $quantita) {
    return $prezzo * $quantita;
}
```

`$prezzo` e `$quantita` sono più chiari di `$a` e `$b`, tranne negli esempi matematici molto piccoli.

## Errore comune: dimenticare di usare il valore di ritorno

```php
<?php
function somma($a, $b) {
    return $a + $b;
}

somma(2, 3);
```

La funzione calcola `5`, ma il valore viene scartato. Se ti serve, salvalo o stampalo:

```php
<?php
$totale = somma(2, 3);
echo $totale;
```
