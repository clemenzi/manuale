## Cos'è PHP?

PHP è un **linguaggio di programmazione per il web**. Serve soprattutto a creare pagine che cambiano in base ai dati, all'utente o a ciò che succede sul sito.

Una pagina HTML normale è come un volantino stampato: tutti vedono la stessa cosa. Una pagina PHP, invece, può preparare contenuti diversi prima di inviarli al browser.

```php
<?php
$nome = "Luca";
echo "Ciao, $nome!";
```

Il codice crea un messaggio usando il valore salvato nella variabile `$nome`.

## Lato server e lato client

Quando apri un sito, il browser riceve HTML, CSS e JavaScript. Questi elementi lavorano sul computer o sul telefono: per questo si dice **lato client**.

PHP lavora prima sul computer che ospita il sito, cioè il **server**. Il server esegue PHP, produce HTML e invia il risultato al browser.

```php
<?php
echo "<h1>Benvenuto</h1>";
```

Il browser non vede il codice PHP: riceve solo l'HTML prodotto.

## Dove si usa PHP

PHP è usato per:

- pagine web dinamiche
- form di contatto
- aree riservate con login
- siti con database
- blog, negozi online e pannelli di amministrazione

Molti progetti famosi, incluso WordPress, usano PHP.

## Cosa imparerai in questa guida

Partiremo dalle basi: installazione, sintassi, variabili e tipi di dato. Poi passeremo a condizioni, cicli, funzioni e array.

Dopo le fondamenta passeremo al web: HTML, form, sessioni, cookie e upload di file. Infine vedremo database, oggetti, gestione degli errori e strumenti come Composer.

L'obiettivo non è imparare tutto a memoria, ma capire abbastanza da leggere codice PHP semplice, modificarlo con sicurezza e costruire piccoli programmi web.

## Cosa devi sapere prima di iniziare

Puoi iniziare anche se non hai mai scritto PHP. Ti aiuterà conoscere almeno l'idea di una pagina HTML, perché PHP viene spesso usato per produrre HTML dinamico.

Non devi conoscere database, oggetti o strumenti professionali. Li incontrerai più avanti, quando le basi saranno già più familiari.

## Come studiare questa guida

PHP si capisce meglio scrivendo codice piccolo e osservando il risultato. Per ogni pagina prova a fare tre cose:

1. copia l'esempio principale in un file `.php`
2. eseguilo con il terminale o con il server locale
3. cambia un valore e guarda come cambia il risultato

Leggere il codice aiuta, ma modificarlo ti fa capire quali parti contano davvero.

## Un esempio molto piccolo

PHP può prendere un dato e usarlo per costruire una risposta.

```php
<?php
$prodotto = "quaderno";
$prezzo = 3.50;

echo "Il prodotto $prodotto costa $prezzo euro.";
```

Output:

```text
Il prodotto quaderno costa 3.5 euro.
```

In poche righe compaiono già tre idee importanti: una variabile, un numero e un testo prodotto dal programma.

## Percorso consigliato

Se parti da zero, segui le sezioni in quest'ordine:

1. installazione e primo programma
2. sintassi, variabili, tipi di dato e operatori
3. condizioni e cicli
4. funzioni e scope
5. array, stringhe e date
6. PHP dentro pagine HTML e form
7. sessioni, cookie e upload
8. database con PDO e query preparate
9. classi, oggetti, errori e strumenti

Le ultime sezioni sono più vicine al lavoro su progetti reali. Non avere fretta: se variabili, condizioni, cicli e funzioni sono chiari, il resto sarà più facile da seguire.
