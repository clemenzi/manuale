---
title: Autoload e namespace
description: Come organizzare file, classi e nomi in progetti PHP piu grandi.
---

## Il problema dei file

In un progetto piccolo puoi usare `require` per includere i file a mano. In un progetto più grande diventa scomodo.

L'autoload carica le classi quando servono, senza dover scrivere `require` per ogni file.

## Namespace

Un namespace è uno spazio dei nomi. Serve a evitare conflitti tra classi con lo stesso nome.

```php
<?php
namespace App\Model;

class Prodotto {
}
```

Il nome completo di questa classe è `App\Model\Prodotto`.

## use

Per usare una classe con namespace puoi importarla con `use`.

```php
<?php
use App\Model\Prodotto;

$prodotto = new Prodotto();
```

Senza `use` dovresti scrivere il nome completo.

## Struttura delle cartelle

Una struttura comune è:

```text
progetto/
  src/
    Model/
      Prodotto.php
  vendor/
  composer.json
```

Il file `Prodotto.php` contiene la classe `App\Model\Prodotto`.

## Autoload con Composer

Nel `composer.json` puoi configurare l'autoload:

```json
{
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  }
}
```

Poi esegui:

```bash
composer dump-autoload
```

Nel codice principale carichi l'autoload:

```php
<?php
require __DIR__ . '/vendor/autoload.php';
```

## Nomi coerenti

Usa nomi di classi chiari e una cartella coerente con il namespace. Così il progetto è più facile da navigare.

## Un file, una classe principale

Una convenzione semplice è mettere una classe principale per file.

```php
<?php
namespace App\Model;

class Prodotto {
}
```

Questo file potrebbe chiamarsi `src/Model/Prodotto.php`. Il percorso rispecchia il namespace.

## Perche serve dump-autoload

Quando cambi la configurazione dell'autoload in `composer.json`, Composer deve rigenerare le informazioni necessarie.

```bash
composer dump-autoload
```

Se aggiungi una nuova classe seguendo la struttura già configurata, spesso non serve fare altro. Se cambi la mappa dei namespace, esegui questo comando.

## Errore comune: namespace e cartella incoerenti

Se dichiari:

```php
<?php
namespace App\Model;
```

ma metti il file in una cartella non collegata ad `App\\`, Composer potrebbe non trovarlo. Quando una classe non viene caricata, controlla il namespace, il nome della classe, il percorso del file e la configurazione `psr-4`.
