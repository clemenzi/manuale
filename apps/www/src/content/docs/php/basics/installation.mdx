## Cosa ti serve

Per scrivere PHP ti servono tre cose:

1. PHP installato sul computer
2. un editor di testo per scrivere codice
3. un terminale per eseguire i comandi

L'editor può essere Visual Studio Code, PhpStorm o un programma simile. Il terminale è la finestra in cui scrivi comandi come `php --version`.

## Installare PHP

Su macOS puoi usare Homebrew:

```bash
brew install php
```

Su Windows puoi installare PHP da `php.net` oppure usare un pacchetto locale come XAMPP. Su Linux di solito puoi usare il gestore pacchetti della distribuzione.

Qualunque metodo tu scelga, alla fine il comando `php` deve funzionare nel terminale.

## Verificare l'installazione

Apri il terminale e scrivi:

```bash
php --version
```

Dovresti vedere un risultato simile:

```text
PHP 8.3.0
```

Il numero può essere diverso. L'importante è che il terminale riconosca PHP e mostri una versione.

## Scegliere una cartella di lavoro

Crea una cartella per gli esercizi, per esempio `corso-php`. In questa cartella metterai i file `.php`.

```bash
mkdir corso-php
cd corso-php
```

`mkdir` crea la cartella. `cd` entra nella cartella.

## Editor consigliato

Un buon editor aiuta con colori, indentazione e segnalazione degli errori. Visual Studio Code è una scelta adatta per iniziare.

> **Suggerimento:** salva sempre i file PHP con estensione `.php`, per esempio `index.php`. Senza questa estensione, PHP non sa che deve eseguire il file come codice.

## Se il comando non funziona

Se il terminale risponde con un messaggio simile a `command not found` o `php non è riconosciuto`, PHP non è ancora raggiungibile dal terminale.

Non significa che hai sbagliato tutto. Di solito la causa è una di queste:

- PHP non e stato installato
- il terminale va chiuso e riaperto
- il percorso di PHP non e stato aggiunto al `PATH`

Il `PATH` è una lista di cartelle in cui il terminale cerca i programmi. Quando scrivi `php`, cerca in quelle cartelle l'eseguibile di PHP.

## Piccola verifica finale

Crea un file chiamato `prova.php` con questo contenuto:

```php
<?php
echo "PHP funziona";
```

Poi eseguilo dalla stessa cartella:

```bash
php prova.php
```

Se vedi `PHP funziona`, l'ambiente è pronto. Da questo punto puoi concentrarti sul codice.
