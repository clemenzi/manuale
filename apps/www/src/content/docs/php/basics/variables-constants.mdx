title: Variabili e costanti
description: Come salvare valori in PHP con variabili e costanti.
---

## Variabili

Una variabile è un nome a cui associ un valore, che puoi usare di nuovo più avanti.

In PHP le variabili iniziano con `$`.

```php
<?php
$nome = "Luca";
$eta = 25;

echo $nome;
```

`$nome` contiene il testo `"Luca"`. `$eta` contiene il numero `25`.

## Cambiare valore

Una variabile può cambiare durante l'esecuzione del programma.

```php
<?php
$totale = 10;
$totale = $totale + 5;

echo $totale;
```

Output:

```text
15
```

PHP legge il valore di `$totale`, aggiunge `5` e salva il risultato nella stessa variabile.

## Nomi validi

Un nome di variabile può contenere lettere, numeri e `_`, ma non può iniziare con un numero.

```php
<?php
$nomeUtente = "Sara";
$prezzo_finale = 19.90;
```

Scegli nomi chiari. `$prezzo` e meglio di `$p`.

## Costanti

Una costante salva un valore che non deve cambiare.

```php
<?php
const IVA = 22;

echo IVA;
```

Le costanti non usano `$`. Per convenzione spesso hanno nomi in maiuscolo.

Puoi anche usare `define`:

```php
<?php
define("NOME_SITO", "Manuale PHP");

echo NOME_SITO;
```

Usa una variabile quando il valore può cambiare e una costante quando deve restare fisso.

## Variabili nei calcoli

Le variabili sono utili quando devi riusare un valore più volte.

```php
<?php
$prezzo = 40;
$sconto = 8;
$totale = $prezzo - $sconto;

echo "Totale: $totale euro";
```

Se il prezzo cambia, modifichi solo `$prezzo`; il calcolo resta lo stesso.

## Errore comune: dimenticare il dollaro

In PHP `$nome` e `nome` indicano due cose diverse.

```php
<?php
$nome = "Luca";
echo nome;
```

Il codice è sbagliato perché `nome` senza `$` non indica la variabile. Quando leggi o modifichi una variabile, usa sempre il dollaro.

## Scegliere tra const e define

All'inizio, usa `const` per dichiarare costanti semplici nei tuoi file.

```php
<?php
const COSTO_SPEDIZIONE = 4.90;
```

`define` esiste ancora e lo incontrerai in molti progetti, ma `const` è più leggibile nei casi semplici.
