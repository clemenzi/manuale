description: Le regole essenziali per scrivere istruzioni PHP leggibili e corrette.

## Il tag di apertura

Il codice PHP inizia con:

```php
<?php
```

Il tag indica a PHP che le righe successive contengono istruzioni da eseguire.

```php
<?php
echo "Ciao";
```

Nei file che contengono solo PHP, di solito non si mette il tag di chiusura `?>`. Evitarlo riduce gli errori causati da spazi o righe vuote alla fine del file.

## Il punto e virgola

In PHP molte istruzioni finiscono con `;`.

```php
<?php
$nome = "Marta";
echo $nome;
```

Il punto e virgola segnala la fine dell'istruzione. Se lo dimentichi, PHP spesso mostra un errore di sintassi.

## Blocchi di codice

Le parentesi graffe `{}` racchiudono più istruzioni in un blocco.

```php
<?php
$eta = 20;

if ($eta >= 18) {
    echo "Puoi entrare";
}
```

Qui il messaggio viene mostrato solo quando la condizione è vera.

## PHP dentro HTML

PHP può essere inserito in una pagina HTML:

```php
<h1>Profilo</h1>

<?php
$nome = "Luca";
echo "<p>Ciao, $nome</p>";
?>
```

HTML descrive la struttura della pagina; PHP prepara le parti dinamiche.

## Spazi e leggibilita

PHP non richiede una spaziatura precisa, ma il codice leggibile è più facile da controllare.

```php
<?php
$prezzo = 10;
$sconto = 2;
$totale = $prezzo - $sconto;

echo $totale;
```

Una riga vuota tra gruppi di istruzioni aiuta a capire il codice.

## Commenti, istruzioni e blocchi insieme

Un piccolo file PHP può contenere tutti questi elementi:

```php
<?php
// Dati di partenza
$nome = "Sara";
$eta = 21;

if ($eta >= 18) {
    echo "Ciao $nome, puoi continuare.";
} else {
    echo "Ciao $nome, questa area non è disponibile.";
}
```

La prima parte prepara i dati, la seconda controlla una condizione. Il blocco tra `{` e `}` contiene le istruzioni da eseguire quando la condizione è vera.

## Errore comune: confondere HTML e PHP

HTML non usa il punto e virgola e non esegue calcoli; PHP, invece, esegue istruzioni.

```php
<p>Questo è HTML</p>

<?php
echo "Questo testo viene prodotto da PHP";
?>
```

Quando una pagina contiene entrambi, chiediti: questa riga descrive la pagina o deve essere eseguita come istruzione?

## Riepilogo

All'inizio, per scrivere PHP corretto, ricorda quattro cose: apri il codice con `<?php`, chiudi le istruzioni con `;`, usa le graffe per i blocchi e mantieni chiari spaziatura e nomi.
