## Cosa significa tipo di dato

Il tipo di dato indica che valore stai usando. Un numero, un testo e un valore vero/falso non si comportano allo stesso modo.

PHP capisce il tipo dal valore che assegni.

## Numeri interi e decimali

Gli interi sono numeri senza parte decimale.

```php
<?php
$eta = 30;
```

I decimali si scrivono con il punto.

```php
<?php
$prezzo = 12.50;
```

## Stringhe

Una stringa è testo racchiuso tra virgolette.

```php
<?php
$nome = "Luca";
$messaggio = 'Ciao';
```

Con le virgolette doppie puoi inserire variabili nel testo.

```php
<?php
$nome = "Luca";
echo "Ciao $nome";
```

## Booleani

Un booleano può avere solo il valore `true` o `false`.

```php
<?php
$maggiorenne = true;
$pagato = false;
```

Li userai spesso nelle condizioni.

## Null

`null` significa che non c'è alcun valore.

```php
<?php
$telefono = null;
```

Non significa zero né stringa vuota: indica l'assenza di un valore.

## Array

Un array raccoglie più valori in una sola variabile.

```php
<?php
$colori = ["rosso", "verde", "blu"];
```

## Controllare il tipo

Per vedere valore e tipo puoi usare `var_dump`.

```php
<?php
$eta = 30;
var_dump($eta);
```

Output possibile:

```text
int(30)
```

`int` indica un numero intero.

## Lo stesso valore puo avere tipi diversi

Guarda questi due valori:

```php
<?php
$numero = 25;
$testo = "25";

var_dump($numero);
var_dump($testo);
```

Il primo è un numero intero. Il secondo è testo, anche se contiene cifre. La differenza conta nei confronti, nei calcoli e nelle validazioni.

## Conversioni semplici

Un valore può arrivare come stringa, per esempio da un form. Se vuoi usarlo come numero, puoi convertirlo.

```php
<?php
$etaDalForm = "32";
$eta = (int) $etaDalForm;

var_dump($eta);
```

`(int)` chiede a PHP di convertire il valore in un intero.

## Errore comune: confondere null e stringa vuota

```php
<?php
$telefono = null;
$indirizzo = "";
```

`$telefono` non ha valore. `$indirizzo` contiene invece un testo vuoto. Nei controlli questa differenza può essere importante.

## Riepilogo

Prima di usare un valore, chiediti che cosa rappresenta: numero, testo, vero/falso, assenza di valore o raccolta di dati. Capire il tipo rende il codice più prevedibile.
