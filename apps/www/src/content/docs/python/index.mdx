## Cos'è Python?

Python è un **linguaggio di programmazione**: ti permette di descrivere una serie di istruzioni che il computer deve eseguire. È noto per una sintassi leggibile e viene usato sia per imparare sia per costruire programmi reali.

Le istruzioni Python assomigliano spesso all'italiano o all'inglese semplice. Leggi questo codice:

```python
if temperatura > 30:
    print("Fa caldo!")
else:
    print("Temperatura nella norma.")
```

Anche senza conoscere la programmazione, puoi intuire cosa fa.

## Dove si usa Python

Python non è usato solo da chi comincia. Compare in molti settori:

- **Siti e servizi web**: per gestire richieste, dati e logica sul server
- **Intelligenza artificiale**: per preparare dati, addestrare modelli e creare strumenti
- **Analisi dati**: i ricercatori e gli scienziati lo usano per elaborare dati
- **Automazione**: per automatizzare compiti ripetitivi al computer
- **Giochi e grafica**: per prototipi e strumenti di sviluppo

## Perché cominciare da Python

- **Sintassi semplice**: richiede meno simboli rispetto ad altri linguaggi
- **Vedi i risultati subito**: non devi compiere passaggi extra per eseguire il codice
- **Funziona ovunque**: su Windows, macOS e Linux
- **Grande ecosistema**: trovi librerie per molti compiti diversi
- **Gratis e open source**: nessun costo, nessuna licenza

## Come funziona Python

Per eseguire un programma Python usi un programma chiamato **interprete**. L'interprete legge il file, controlla il codice e lo esegue.

Questa spiegazione è sufficiente per iniziare. Internamente Python compie più passaggi, ma non devi gestirli a mano come la compilazione di un programma C++.

Il flusso di lavoro è questo:

1. Scrivi il codice in un file con estensione `.py`
2. L'interprete Python legge ed esegue il file
3. Vedi il risultato nel terminale

## Installazione

Scarica Python dal sito ufficiale: **python.org/downloads**

Durante l'installazione su Windows, assicurati di spuntare la casella **"Add Python to PATH"**, altrimenti il terminale non troverà Python.

Verifica che l'installazione sia andata a buon fine aprendo il terminale e digitando:

```bash
python --version
```

Dovresti vedere un numero di versione che comincia con `Python 3`.

## Il primo programma

Per tradizione, il primo programma mostra un saluto. In Python basta una riga:

```python
print("Hello, World!")
```

Salva questo codice in un file chiamato `hello.py`. Poi apri il terminale nella stessa cartella e digita:

```bash
python hello.py
```

Output:

```
Hello, World!
```

`print()` è una **funzione**, cioè un'operazione già pronta che puoi richiamare. In questo caso mostra testo nel terminale. All'inizio la userai spesso per osservare i risultati del codice.

## La console interattiva (REPL)

Python ha anche una modalità interattiva: digita `python` nel terminale (senza indicare un file) e puoi scrivere istruzioni una alla volta, vedendo subito il risultato.

```
>>> print("Ciao!")
Ciao!
>>> 2 + 3
5
>>> nome = "Alice"
>>> print("Ciao,", nome)
Ciao, Alice
```

Le `>>>` indicano che Python è in attesa di un'istruzione. La modalità interattiva è utile per provare rapidamente una piccola idea senza creare un file.
