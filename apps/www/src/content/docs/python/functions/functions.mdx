## A cosa servono le funzioni?

Se devi calcolare tre volte la media dei voti, senza una funzione dovresti ripetere la formula tre volte. Una modifica richiederebbe poi di intervenire in tutti i punti.

Con una funzione scrivi il calcolo **una volta sola**, gli dai un nome e lo riusi. Per cambiarlo, modifichi un solo punto.

## Creare una funzione

Si usa la parola chiave `def` (abbreviazione di "define", definire):

```python
def saluta():
    print("Ciao!")
```

La funzione si chiama `saluta` e, quando viene eseguita, stampa "Ciao!". La definizione, però, non esegue ancora il corpo della funzione.

## Chiamare una funzione

Per eseguirla, la "chiami" scrivendo il nome seguito dalle parentesi:

```python
saluta()  # esegue la funzione → stampa "Ciao!"
saluta()  # puoi richiamarla quante volte vuoi
saluta()
```

## Passare informazioni: i parametri

Una funzione può ricevere informazioni dall'esterno attraverso i **parametri**:

```python
def saluta(nome):
    print(f"Ciao, {nome}!")

saluta("Alice")   # Ciao, Alice!
saluta("Bob")     # Ciao, Bob!
saluta("Carlo")   # Ciao, Carlo!
```

La stessa funzione può comportarsi in modo diverso in base agli argomenti ricevuti. Puoi anche definire più parametri:

```python
def somma(a, b):
    print(a + b)

somma(3, 5)    # 8
somma(10, 20)  # 30
```

## Restituire un risultato: `return`

Finora le funzioni hanno stampato un messaggio. Spesso invece vuoi che una funzione **calcoli qualcosa e restituisca il risultato**, così da poterlo usare in seguito.

Si usa la parola chiave `return`:

```python
def somma(a, b):
    return a + b

risultato = somma(3, 5)
print(risultato)         # 8
print(somma(10, 20) * 2) # 60: puoi usarlo direttamente nelle espressioni
```

Quando Python incontra `return`, esce dalla funzione e restituisce il valore indicato. Senza `return`, la funzione restituisce automaticamente `None`.

## Valori predefiniti per i parametri

Puoi assegnare un valore predefinito a un parametro. Se durante la chiamata non passi un argomento, viene usato quel valore:

```python
def saluta(nome, saluto="Ciao"):
    print(f"{saluto}, {nome}!")

saluta("Alice")               # Ciao, Alice!  Usa il default
saluta("Bob", "Buongiorno")   # Buongiorno, Bob!  Sovrascrive il default
```

I parametri con valore di default devono sempre venire **dopo** quelli senza.

## Passare argomenti per nome

Durante la chiamata puoi indicare il nome dei parametri. In questo caso l'ordine non è rilevante:

```python
def descrivi_persona(nome, eta, citta):
    print(f"{nome} ha {eta} anni e vive a {citta}.")

# Ordine normale
descrivi_persona("Alice", 16, "Roma")

# Con i nomi: l'ordine non importa più
descrivi_persona(eta=16, citta="Roma", nome="Alice")
```

## Restituire più valori

Una funzione può restituire più valori contemporaneamente:

```python
def min_max(numeri):
    return min(numeri), max(numeri)

piccolo, grande = min_max([3, 1, 4, 1, 5, 9])
print(piccolo)  # 1
print(grande)   # 9
```

## Esempio pratico

```python
def calcola_media(voti):
    if len(voti) == 0:
        return 0
    return sum(voti) / len(voti)

def classifica_voto(media):
    if media >= 9:
        return "Ottimo"
    elif media >= 7:
        return "Buono"
    elif media >= 6:
        return "Sufficiente"
    else:
        return "Insufficiente"

voti_alice = [8, 7, 9, 6, 10]
media = calcola_media(voti_alice)
giudizio = classifica_voto(media)

print(f"Media: {media:.1f}, {giudizio}")
# Media: 8.0, Buono
```

Il programma principale mostra l'intento del codice senza dover leggere l'implementazione interna delle funzioni.
