## A cosa serve pip

Python include molte funzionalità, mentre la comunità mette a disposizione **librerie esterne** per grafica, analisi dei dati, intelligenza artificiale, giochi e siti web.

**pip** scarica e installa queste librerie.

## Cos'è pip?

**pip** è il gestore di pacchetti di Python. Installa pacchetti dal **PyPI**, il deposito ufficiale disponibile all'indirizzo pypi.org.

pip è già incluso con Python e non richiede un'installazione separata.

## Verificare che pip funzioni

Apri il terminale (o il prompt dei comandi su Windows) e digita:

```bash
pip --version
# pip 24.0 from /usr/lib/python3/dist-packages/pip (python 3.x)
```

Se hai sia Python 2 che Python 3, potrebbe servire `pip3`:

```bash
pip3 --version
```

## Installare una libreria

```bash
pip install nome-libreria
```

Per esempio, puoi installare `requests` per fare richieste web:

```bash
pip install requests
```

Installare una versione specifica (utile quando un progetto richiede esattamente una certa versione):

```bash
pip install requests==2.31.0
```

Aggiornare una libreria all'ultima versione disponibile:

```bash
pip install --upgrade requests
```

## Disinstallare una libreria

```bash
pip uninstall requests
```

## Vedere le librerie installate

```bash
pip list
```

Output di esempio:

```
Package    Version
---------- -------
pip        24.0
requests   2.31.0
numpy      1.26.0
```

## Il file `requirements.txt`: condividere le dipendenze

Quando condividi un progetto, il file `requirements.txt` elenca le librerie necessarie per installarlo.

**Creare il file** (salva le librerie attualmente installate):

```bash
pip freeze > requirements.txt
```

Contenuto tipico di `requirements.txt`:

```
requests==2.31.0
numpy==1.26.0
pandas==2.1.0
```

**Installare tutto** da un `requirements.txt` (utile quando ricevi un progetto da qualcun altro):

```bash
pip install -r requirements.txt
```

## Ottenere informazioni su una libreria

```bash
pip show requests
```

Output:

```
Name: requests
Version: 2.31.0
Summary: Python HTTP for Humans.
Home-page: https://requests.readthedocs.io
```

## Librerie popolari da conoscere

| Libreria         | A cosa serve                                                  |
| ---------------- | ------------------------------------------------------------- |
| `requests`       | Scaricare dati dal web, fare richieste HTTP                   |
| `numpy`          | Calcoli matematici veloci su grandi quantità di numeri        |
| `pandas`         | Analisi e manipolazione di dati (come Excel ma programmabile) |
| `matplotlib`     | Creare grafici e visualizzazioni                              |
| `flask`          | Creare siti web semplici                                      |
| `django`         | Creare siti web completi                                      |
| `pillow`         | Modificare immagini                                           |
| `pygame`         | Sviluppare videogiochi 2D                                     |
| `beautifulsoup4` | Estrarre dati da pagine web                                   |

## Buone pratiche

- Usa sempre un **ambiente virtuale** per ogni progetto (vedi il capitolo successivo)
- Tieni aggiornato il file `requirements.txt` quando aggiungi librerie
- Prima di installare una libreria sconosciuta, verifica che sia affidabile: guarda quante stelle ha su GitHub e quanti download ha su PyPI
